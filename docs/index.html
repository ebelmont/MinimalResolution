MinimalResolution

A p=3 fork of Guozhen Wang's minimal-resolution code for computing the Adams–Novikov E2 page for the sphere, via the algebraic Novikov spectral sequence. This page is the entry point into documentation generated from the actual source (with file:line citations) — start with Architecture if you're new here.

⚠ Read this first: the "p=3 fork" is partial — and now explained. Only mr_st and the BP pipeline (BPtab/mr_BP) actually run at p=3. kos, mr_ex, and the entire motivic pipeline are hardcoded to p=2 because they're an independent cross-check via the motivic Adams spectral sequence for the cofiber of τ (Gheorghe–Wang–Xu), not an unfinished part of the port. See Architecture §6 for the full story.
